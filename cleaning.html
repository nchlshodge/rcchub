Cleaning & setup

Setup and tear-down tasks for every approved event, plus the regular cleaning jobs, all on one calendar for Don.

Admins only

This page is for admins. If you need something on the cleaning calendar, ask Nick or Stephanie.

For each approved event, tick what it needs: Setup and Cleaning before, Tear down and Cleaning after. Every room the event uses gets its own tasks on the cleaning calendar. Say what needs to be set up in each room, and what can stay up afterwards. It goes to the calendar as soon as you save. An event nobody has marked gets setup before, plus tear down and cleaning after.
