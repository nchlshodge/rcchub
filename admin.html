App Access

"Apps" controls which tiles show on each person's hub dashboard. "Roles" grants department-scoped admin access — e.g. Van Usage Admin can approve drivers and manage vans, but has no access to Bedside, Graphics, or Marketing, and vice versa. Full admin access is still managed separately under "Manage Admins."
